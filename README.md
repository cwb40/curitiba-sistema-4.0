# 🧠 Sistema 4.0 de Curitiba

Este projeto tem como objetivo criar um **sistema inteligente 4.0** para a cidade de **Curitiba**, capaz de **analisar e prever fluxos de trânsito, transporte público, condições climáticas, segurança pública e saúde urbana** — tudo usando **APIs abertas**, **mapas públicos** e **Inteligência Artificial**.

---

## 🎯 Missão
Desenvolver uma plataforma totalmente **aberta e em nuvem**, que integre dados públicos e privados para melhorar a **gestão urbana** e **qualidade de vida** da população.

---

## 🧩 Estrutura inicial
- **Dados e IA** — coleta e modelagem preditiva  
- **Backend** — API central com FastAPI (Python)  
- **Frontend** — painel web com mapas (OpenStreetMap + React)  
- **Infraestrutura** — hospedagem em nuvem (GitHub, Render, Netlify)
